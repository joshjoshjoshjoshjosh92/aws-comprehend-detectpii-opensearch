# Changelog

All notable changes to this project will be documented here.

---

## [1.0.0] — 2025

### Added
- Initial reference architecture for PII detection in Amazon OpenSearch using Amazon Comprehend
- EC2-based Python processor for document ingestion, Comprehend API orchestration, and redaction
- Configurable PII entity types and handling modes (`REDACT` / `FLAG`)
- IAM least-privilege policy templates
- Implementation guide and supporting collateral
- Published to AWS PACE Program — Financial Services Industry Segment
- Recognized in Amazon internal reuse tracking system
